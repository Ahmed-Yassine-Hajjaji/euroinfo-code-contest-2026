## Modèle (`src/m10_cp.py`)
- Rôles d'un modèle libre m : f_m (plein), h_m (demi), y_m (générateur si mono réalisable), z[m,t] (besoin t couvert par un
  générateur, z ≤ h ; z = h si lb > ub, f interdit si un besoin est impossible) ; f + h + y ≤ 1.
- Créneau (m, t) : actif a = f + h − z (modèle multi) ou f + h + y − z (mono) ; lb·a ≤ Σ taille·x[d,(m,t)] ≤ ub·a.
  Créneaux des modèles fixés : a = 1 (constantes). Dataset dans ≤ 1 créneau ; copyright : x[d,·] ⇒ ¬f_m (plein tarif = libres
  seulement). Par type : Σ z (cibles) + cibles fixées ≤ Σ y + générateurs fixés. Énergie : Σ e(f+h+y) ≤ cap − énergie fixée.
- Objectif = Σ v·f + (v//2)·h + valeur fixée = score exact (vérifié : décodage avec `fix_variables_to_their_hinted_value`
  → 669 156 = `evaluate` officiel, sans et avec `--type`).
- Décodage : x = 1 → dataMappings ; appariement générateurs/cibles par type (zip) ; générateurs excédentaires abandonnés.
  Callback : chaque solution de valeur > meilleur connu est décodée, validée par le scoreur officiel, écrite dans
  `runs/m10_<tag>_best.json` et passée à `src/save_if_better.py 6 ... --method "m10 ..."`.
- Symétries : datasets jumeaux (type, taille, copyright, même support) ordonnés (utilisé(d1) ≥ utilisé(d2)) : 20-24 paires.
- Tours : `--rounds R --time T` : après chaque tranche, le hint est remplacé par la meilleure solution validée (`ClearHints` +
  `AddHint`), graine incrémentée.

## Réduction (fixations) — constat clé
- Le pool (12 solutions m6 à 669 153-669 156 + best) a **des rôles identiques à 2 modèles près** : la fixation par le pool ne
  libère rien. Liberté ajoutée par coût réduit LP (`runs/lp_6.json`, duaux énergie / données libres / totales / générateurs) :
  `--lpk K` modèles inutilisés par rôle (f, h, y), `--targets K` cibles demi-tarif (bascule h → f), `--worst K` modèles pleins
  et générateurs au pire coût réduit (candidats au retrait).
- Support des x : paires (dataset, créneau) de toutes les solutions du pool (18 717) ; `--full-free` : tous les datasets
  compatibles pour les créneaux des modèles libres ; `--small S` : datasets de taille ≤ S candidats dans tous les créneaux
  actifs de leur type (pièces d'appoint : 268 datasets ≤ 500, 415 ≤ 800).
- `--type t` : modèle restreint au type t (modèles mono-type t libres, créneaux de type t seulement, les autres types fixés
  au hint et recopiés au décodage) : 4 × moins de variables pour la même liberté. Les cibles couvertes par 1 générateur sont
  mono-besoin (1 178 / 1 249) → le levier principal (bascule cible → plein tarif, échange de générateurs) est mono-type.
